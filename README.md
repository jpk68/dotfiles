# jpk68's dotfiles

How to use:

1. Clone the repo
2. Run `./bootstrap.sh`

Alternatively, just download the script and run it.

## Requirements

- [`vim-plug`](https://github.com/junegunn/vim-plug) (for loading Vim plugins)
- [Prettier](https://github.com/prettier/prettier), [`sh`](https://github.com/mvdan/sh), and [`mbake`](https://github.com/EbodShojaei/bake) (for formatting stuff)
